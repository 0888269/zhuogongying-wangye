如何用 NFC Tools Pro 写卡
  1. 选中成员，点击“复制名片网址”。
  2. 在 NFC Tools Pro 的“写入 / Write”中添加“URL / URI”记录，粘贴完整网址并确认。
  3. 点击写入，将卡片靠近手机，等待成功。换下一位时，替换上一位的网址记录，确保只保留当前成员的网址。
  4. 读取卡片，打开网址核对姓名，再回来点击“标记已写入”。

复制网址不会自动标记完成。“已写入”是你手动确认的记录。
